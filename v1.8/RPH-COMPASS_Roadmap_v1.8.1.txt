PROJECT IDENTITY
================
RPH-COMPASS
Rotor, Piston, Hinge - Component Orientation, Motion And Positional Assessment Status System
"Monitoring position. Assessing motion. Maintaining awareness. Precision is our direction."

STRICT CODE ADHERENCE PRINCIPLES
================================
1. Maintain compatibility with standard Space Engineers INI-style Custom Data.
2. Preserve PARK script data integrity (never write or modify [PARK:*] sections).
3. Use ASCII-only characters for all script output, custom data, and documentation.
4. Avoid redundant writes to Custom Data unless explicitly commanded (for example: rebuild_cd).
5. Ensure user-facing configuration keys remain consistent across all modules.
6. Modularize features for scalability and future expansion.

[-] Compact renderer must always write display text even when autosize is disabled
- render text to surface unconditionally
- apply autosize only as an optional post-step
- purpose: prevent "no update" condition on compact LCDs with autosize=false

[-] Echo and logging control for display-related operations
- use a centralized echo helper (SafeEcho) for all user-facing messages in display and refresh paths
- allow multiple echos per run so the user can actually see warnings and summaries in PB console
- keep messages short to avoid PB terminal clipping
- must be ASCII-only

[p] Longer-term echo variant
- consolidate into a single buffered output per run if game terminal behavior allows
- target: mitigate PB console clipping in large grids
- impact: display/logging only, no change to data model
