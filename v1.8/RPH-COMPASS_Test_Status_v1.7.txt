v1.7.3 Display System Tests

- LCD compact mode (grouped per line): PASS
- LCD full mode with rph_group_separators=true and rph_sort=group: PASS
- LCD full mode with rph_group_separators=true and rph_sort=default: N/A (by design, grouping requires group sort)
- Per-LCD autosize (rph_display_autosize=true): PASS (tuned to longest-line heuristic) (pending changes with per-font resizing)
- Autosize expansion for short lines: PASS (ladder tuned for FontSize ~1.2 baseline)
- PB Echo head-up for missing headers: PASS (note: PB terminal clips top lines if too many Echo() calls issued in same run)
- Rebuild_cd repopulates LCD CD with new keys (autosize, separators): PASS (v1.7.1 hotfix)
- PARK coexistence after v1.7 changes: PASS (no writes to [PARK:*])

Known Issues (v1.7.3)
- PB terminal display may show only last line of multi-line echo
- Autosize can shrink too aggressively for extremely long display names; clamp to be revisited in v1.8 with per-font ladder
   implementation
- Monospace vs Debug font width differences not yet normalized
