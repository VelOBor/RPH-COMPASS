"Monitoring position. Assessing motion. Maintaining awareness. Precision is our direction."


STRICT CODE ADHERENCE PRINCIPLES
================================
1. Maintain compatibility with standard Space Engineers INI-style Custom Data.
2. Preserve PARK script data integrity (never write or modify [PARK:*] sections).
3. Use ASCII-only characters for all script output, custom data, and documentation.
4. Avoid redundant writes to Custom Data unless explicitly commanded (e.g., rebuild_cd).
5. Ensure user-facing configuration keys remain consistent across all modules.
6. Modularize features for scalability and future expansion.

[v] - feature is considered complete, works as designed
[r] - feature is removed from the docket until further notice
[p] - feature is planned for future upgrade, not explored or proven feasible
