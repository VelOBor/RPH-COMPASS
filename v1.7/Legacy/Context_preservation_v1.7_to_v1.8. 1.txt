- We are writing a script for the game "Space Engineers" by 
	Keen Software House
- The script language is an "abridged" version of C# (perhaps C#-6?) 
	which runs in a sandboxed environment of Space Engineers game's
	"programmable block"
- We use MDK-SE on GitHub for reference, as well as any specified scripts
	from the Space Engineers Steam Workshop (id## provided as needed)

STRICT CODE ADHERENCE PRINCIPLES

INI-style Custom Data only (Space Engineers compatible)

Never write or modify [PARK:*] sections

ASCII-only for all script output and docs

Per-LCD configuration must use [RPH:Display]
