⚙️ Phase 4 – Refresh Echo & Header Warning
Symptoms observed:


Heads-up appears as expected when RPH headers missing ✅


Rebuild produces no visible echo ✖️


Refresh shows only final line, and partial vertical clipping at top ✖️


Diagnosis:
That’s a classic terminal scroll offset artifact in SE’s PB terminal.


Echo() doesn’t scroll automatically when the buffer fills.


If multiple Echo() calls happen in a single tick, the PB sometimes renders the bottom line only.


Fix plan:


In v1.8, consolidate multi-line Echo output into one call:
Echo(log.ToString());

where log is a StringBuilder that accumulates all text.


This will restore full, readable output and prevent scroll truncation.


No functional impact — safe to defer to next version.

🔤 Phase 7 – Font Behavior / Monospace Divergence
Excellent callout, Captain. The differences are due to font metrics variance:


“Debug” font is variable-width, less predictable.


“Monospace” gives precise per-character width, perfect for compact tables.


Recommendation for v1.8:


On LCD init, detect Surface.Font.


If it’s neither "Debug" nor "Monospace", automatically set it to "Monospace".


Maintain separate autosize ladders for both fonts.


This keeps user freedom while standardizing behavior.
